MY TIMESHEET - ANDROID APK BUILD

This project is a native Android app. It stores punches locally on the phone
and uses Asia/Qatar time.

HOW TO BUILD THE APK ON WINDOWS
1. Install Android Studio.
2. Open Android Studio.
3. Choose "Open" and select the MyTimesheetAndroid folder.
4. Let Gradle Sync finish.
5. Choose: Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Android Studio will show "APK(s) generated successfully".
7. Click "locate".

Typical APK location:
app\build\outputs\apk\debug\app-debug.apk

Move app-debug.apk to your Android phone and open it.
Android may ask you to allow installation from that file manager/browser.

APP FEATURES
- One-tap Punch In
- One-tap Punch Out
- Asia/Qatar timestamps
- Local offline storage
- This-month history
- Total worked hours
- Export current month to Word-compatible .doc
- No account or internet required

NOTE
This is an unsigned/debug APK when built with "Build APK(s)", suitable for
personal installation/testing. For Play Store distribution, create a signed
release build instead.
